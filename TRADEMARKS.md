### Maintainer to-do (brand protection)
Copyright in this code exists automatically from the moment it's written. No one else can
"copyright" it. Registration is optional but helps enforcement.

A *name* can't be copyrighted; it is protected by **trademark**. To make "firmgap" defensible:
1. Search the marks: USPTO (https://tmsearch.uspto.gov), India IP Office (https://ipindia.gov.in),
   EUIPO and WIPO Global Brand Database. Check classes 9 (software) and 42 (SaaS / consulting).
2. If it's clear, file in your home jurisdiction first, then via the Madrid Protocol if needed.
   An IP attorney makes this reliable.
3. Reserve the namespaces now: crates.io `firmgap` (first `cargo publish`), GitHub org `firmgap`, and
   domains (`firmgap.dev`, `firmgap.io`).
4. Use the mark consistently ("firmgap™") until registration, then ®.
